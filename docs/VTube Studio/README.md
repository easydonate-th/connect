# VTube Studio

<img width="600" height="400" alt="demo" src="demo.gif" />

## Requirements

- [VTube Studio](https://denchisoft.com/) installed
- [EasyDonate](https://easydonate.app) account

## Installation

1. Install the [latest release](https://github.com/easydonate-th/connect/releases) of the desktop app
2. Enable the Plugin API in VTube Studio

<img src="image.png" alt="Plugin API setting in VTube Studio" width="360" />

3. Open the desktop app, Go to **Integrations > VTube Studio** and click **Connect** test connection. The VTube Studio will pop up a prompt to allow the plugin. Click **Allow**

<img src="image-1.png" alt="VTube Studio connection settings in the desktop app" width="560" />

<img src="image-2.png" alt="VTube Studio plugin permission prompt" width="440" />

4. Choose or upload image and test it with, **Send Test Donation**

5. Choose a **Hit sound** and its **Volume**, then click **Preview** to hear it. When an item hits your model, the app plays the sound. To put the sound on stream, capture desktop audio in your streaming software.

   To use your own sound, click **Add sounds** and choose MP3, WAV or OGG files under 5 MB. The app adds them to the **Hit sound** list under **Your sounds** and selects the first one. To remove a sound, select it and click the trash button. The app deletes the removed file when you save.
